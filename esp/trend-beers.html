Trend Beers

Descripción general

El objetivo principal fue conceptualizar y diseñar la interfaz de usuario (UI) para un nuevo e-commerce dedicado a la importación y venta de cervezas belgas de alta gama (marcas como Straffe Hendrik, Brugse Zot y Blanche De Bruges).

El cliente buscaba una plataforma que equilibrara la funcionalidad de venta directa con una estética visual rica y envolvente.

Proceso de diseño

Para este proyecto, el objetivo fue optimizar la jerarquía de información y elevar la estética visual para alinearla con la exclusividad de las cervezas. Los cambios clave fueron:

Referentes gráficos

Para el moodboard de referentes gráficos, busqué sitios con características únicas que conectaran con la temática de la cervecería. El enfoque principal fue encontrar layouts dinámicos y no estáticos, que presentaran la información de manera funcional pero con elementos visuales diferenciadores.

Aunque el concepto inicial exploraba colores como rojo y amarillo sobre gris, finalmente decidí llevar la estética hacia un tono oscuro y formal. Esta decisión permite que el diseño coincida con la fotografía de producto de las cervezas, resaltando su calidad y manteniendo una identidad visual coherente.

Mapa de navegación

Antes de enfocarme en el diseño, creé un mapa de navegación para orientarme en las páginas que iban a conformar todo el sitio web.

Guia de estilo

Ver Design system en Figma

Para garantizar la coherencia y facilitar la escalabilidad del proyecto, desarrollé un sistema de diseño que incluye una paleta cromática optimizada para entornos oscuros, una jerarquía tipográfica clara y componentes modulares.
